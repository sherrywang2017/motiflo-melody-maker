# Motiflo — online melody maker

![Motiflo logo](assets/logo.png)

[Open Motiflo](https://motiflo.win/) · [Listen to examples](https://motiflo.win/listen/) · [Plans](https://motiflo.win/pricing/) · [Help](https://motiflo.win/help/)

Motiflo helps you turn a short musical idea into a melody you can hear, read, save, and export. Choose a style, mood, instrument, key, and tempo, or enter your own opening notes. Motiflo generates up to three short candidates in a batch for piano, violin, or voice.

You can listen in the browser, read sheet music, and export MIDI, MusicXML, WAV, or a project file. Motiflo uses an algorithmic composition engine; it is not a generative audio model.
